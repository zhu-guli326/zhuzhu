# FrameLab

FrameLab 是一个浏览器内运行的手势取景视频合成工具。上传原始视频和框内视频后，页面会识别双手形成的取景框，并在本地预览和导出合成结果。

## 功能

- 双视频合成：原始视频用于手势识别，框内视频显示在双手形成的画面中。
- 示例体验：内置示例素材，可先直接预览效果。
- 手势定位：自动识别双手，也支持手动调整四角和铺满画面。
- 局部特效：支持故障闪切、霓虹扫描、暗场聚焦等效果。
- 本地导出：素材处理在浏览器中完成，不会主动上传视频。
- 实时摄像头：`live.html` 提供摄像头手势框与实时滤镜。

## 本地运行

```bash
python3 -m http.server 8124
```

打开 `http://127.0.0.1:8124/`，实时摄像头模式为 `http://127.0.0.1:8124/live.html`。

## 部署到 Vercel

项目是纯静态网页，Vercel 设置如下：

```text
Framework preset: Other
Build command: npm run build
Output directory: dist
```

`vercel.json` 已包含相同配置。生产域名使用 `zhuzhu.store`。

## 分析统计

页面接入 Vercel Web Analytics 和 Google Analytics 4。埋点只记录功能操作及文件技术属性，例如类型、大小区间、时长和分辨率，不上传文件名或视频内容。

建议在 GA4 中将 `export_completed` 标记为关键事件。

## 隐私说明

静态网页版本在浏览器本地处理素材，不需要 API key，也不会主动上传视频。输入视频、导出视频、模型文件和临时缓存均已加入忽略规则；仓库只保留源码和示例媒体。
